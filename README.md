# Argus

Argus checks your Microsoft 365 security settings and shows what has drifted, with plain-English fixes. It runs in your
own Azure subscription and only reads.

- **Install guide:** [INSTALL.md](https://github.com/Higate-Security/argus-connect/blob/v0.2.26/INSTALL.md), for Argus 0.2.26.
- **Releases:** each one holds the install guide, the deployment template (`azuredeploy.json`), Argus Connect (the
  script the deployment's last step runs) and `SHA256SUMS.txt`.
